# Tarjetas de regalo

Las tarjetas de regalo de Norte Retail se compran en valores de 50.000, 100.000, 200.000 y 500.000 COP. Son digitales: llegan por correo al destinatario con un código de 16 caracteres.

## Vigencia y uso

Cada tarjeta vence 12 meses después de la compra. Se puede usar en varias compras hasta agotar el saldo, y se combina con cualquier medio de pago para cubrir la diferencia. No se puede usar para comprar otras tarjetas de regalo.

## Lo que no se permite

Las tarjetas de regalo no se devuelven, no se cambian por dinero en efectivo y no se reembolsan, ni siquiera el saldo restante. Si una compra pagada con tarjeta de regalo se devuelve, el valor se abona de nuevo a la misma tarjeta, no a otro medio de pago.

## Tarjeta perdida

Si el destinatario borró el correo, el comprador puede reenviar el código desde "Mis pedidos". Norte Retail no repone tarjetas cuyo código ya fue usado por otra persona.
